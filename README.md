# fluffy-meme

Strona internetowa dla oferty pelletu Premium A1.

## Opis projektu

To prosta strona produktowa przygotowana w formie statycznej witryny HTML/CSS/JS. Projekt zawiera:
- stronę główną,
- regulamin,
- sekcję kontaktową,
- grafikę logo i baneru,
- podstawowe skrypty interakcji.

## Pliki w repozytorium

- `index.html` – strona główna.
- `style.css` – style strony.
- `script.js` – logika JavaScript.
- `regulamin.html` – podstrona z regulaminem.
- `logo-sosnowe-chwile.jpg` – logo projektu.
- 'baner-sosnowe-chwile-1920x1200.jpg' – grafika baneru.

## Funkcje

- responsywny układ strony,
- prezentacja oferty pelletu,
- sekcja regulaminu,
- prosta nawigacja i interakcje,
- przygotowanie pod publikację na GitHub Pages.

## Technologie

- HTML5
- CSS3
- JavaScript

## Uruchomienie lokalne

1. Sklonuj repozytorium.
2. Otwórz plik `index.html` w przeglądarce.
3. Możesz też uruchomić projekt przez lokalny serwer, np. Live Server.

## GitHub Pages

Projekt można wdrożyć na GitHub Pages, wskazując plik `index.html` jako stronę główną.
